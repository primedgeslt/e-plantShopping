# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is a React-based online plant nursery application for browsing and purchasing indoor plants. The application allows users to explore different plant categories, view plant details, add plants to a shopping cart, and manage cart quantities.

## Features

- Landing page for Paradise Nursery
- Navigation links for Home, Plants, and Cart
- Plant listings organized into multiple categories
- Plant cards with:
  - Plant image
  - Name
  - Description
  - Price
  - Add to Cart button
- Dynamic cart item count
- Shopping cart with:
  - Product thumbnails
  - Unit prices
  - Quantity controls
  - Delete buttons
  - Total item count
  - Total cost
- Checkout button displaying a “Coming Soon” message
- Continue Shopping button linking back to the plant listings

## Technologies Used

- React
- JavaScript
- JSX
- CSS
- Redux Toolkit

## Project Structure

Important project files include:

- `README.md` — Project description and documentation
- `AboutUs.jsx` — Company information
- `App.jsx` — Main application and landing page
- `App.css` — Application styling and background image
- `ProductList.jsx` — Plant product listings
- `CartSlice.jsx` — Shopping cart state management
- `CartItem.jsx` — Individual cart item component

## Getting Started

1. Clone or download this repository.
2. Install the project dependencies.
3. Start the React development server.
4. Open the application in a browser.
